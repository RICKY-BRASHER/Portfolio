# Portfolio

Base de portfolio construite avec React, TypeScript et Vite.

## Démarrer

```bash
npm install
npm run dev
```

## Personnaliser

- Modifiez le contenu, les liens et les projets dans `src/App.tsx`.
- La photo de profil affichée est `public/photo_cv.JPG`.
- Le CV téléchargeable est `public/Cv-Portfolio.pdf`.
- Adaptez les couleurs et les styles globaux dans `src/index.css`.

## Technologies

- React et TypeScript
- Vite
- Tailwind CSS 4
- Framer Motion
- Lucide React
- Simple Icons (logos SVG des technologies)

Les projets et certifications doivent correspondre à des réalisations et titres
réels. Ajoutez-les dans `src/App.tsx` lorsqu'ils sont prêts à être présentés.

## Vérification de production

```bash
npm run build
```
